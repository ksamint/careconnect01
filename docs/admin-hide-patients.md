# 管理员隐藏及恢复患者

管理员登录后：管理控制台 → 临床端 → 打开患者 → 患者管理（管理员）→ 隐藏患者 → 填写原因（例如 T2 超窗）→ 确认隐藏，保留数据。

恢复：临床首页 → 已隐藏患者（管理员可恢复）→ 按患者编号核对 → 恢复。

隐藏须人工确认，不自动判定 T2 超窗。隐藏后患者登录及新提交被拒绝；已有患者会话失效。患者、作答、修订、联系及处置的数据库记录保留，隐藏和恢复均记入审计。隐藏与退出研究分别记录，恢复不改变原有退出状态。

日常列表及研究端导出不含隐藏患者及其作答。管理员可在已隐藏名单查看编号、隐藏时间和原因。既有管理员日报读取保留数据库记录，因此累计收表仍包括隐藏患者；隐藏不构成研究分析排除决定。

权限：仅 system_admin / org_admin 可隐藏及恢复。临床普通账号、研究账号和患者均无操作权限。截图应使用本地演示数据，不展示真实患者资料。

验证：API 回归检查权限、原因必填、会话撤销、登录与提交阻断、列表过滤、SQLite 原始行保留、恢复及审计；前端 TypeScript/Vite 构建。全仓 ESLint 有既存 AppContext.tsx fast-refresh 三项错误。
