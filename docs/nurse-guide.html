症状问卷 · 护士采集指南

日间化疗症状群课题（C-194）。每位患者、每个化疗周期，填 3 次同一份 19 题问卷。下面先看时间点，再看每天要做的 3 件事，遇到具体情况点开对应卡片。

什么时候填：以输注当天为第 0 天

T0第 −1 天前 1 天 ~ 输注前
输注第 0 天化疗当天
T1第 3 天第 2–4 天
T2第 8 天第 7–9 天

系统按输注日期自动算好这些日子。超出范围也可以填，数据保留，导出时会自动标“超窗”。T0 一定要在开始输液之前完成。

每天上班做 3 件事

  1. 登录，打开「今日待随访」用护士账号登录手机或平板，首页默认就是今天该随访的患者。
  2. 先处理红色预警点「待处置预警」，逐个打电话或安排就医，然后点 记录预警处置。
  3. 再催今天没填的人按「提醒三步」联系，每联系一次就点 记录提醒。有纸质问卷的，当天录入。

遇到这些情况，这样做

入

新患者入组签完知情同意书之后
  1. 首页点 新患者入组。
  2. 代称写床号或缩写（如“12 床”），不要写真实姓名。
  3. 填签同意书的日期、第 1 周期的输注开始日。
  4. 勾选“为患者开通手机填写账号”，点 确认入组。
  5. 屏幕上出现账号和 6 位密码，只显示这一次：抄在患者须知卡上交给患者。
  6. 当场教患者在手机上登录，填完 T0。
  7. 当天把人口学和临床资料补齐（患者页面点「基线资料」，临床资料从 HIS 查）。

密码忘了：患者页面点「患者登录账号」重新生成一个新密码即可。

手

患者自己用手机填最常见的情况
  1. 患者登录后首页会出现“完成 T1 症状评估”这类任务，点进去。
  2. 每屏一道题，点 0–10 的数字，再点“下一题”。不想答的题点“跳过此题”。
  3. 最后一屏核对，点“确认并提交”。

每点一下都会自动保存。中途退出、关掉微信、换手机，再登录会从断开的那题继续。没网也能提交，联网后自动上传。

代

患者不会用手机 / 视力不好在病房当面填
  1. 打开患者页面，在要填的时点下点 现场填写。
  2. 选“患者自己在本设备上填写”（平板递给患者），或“护士读题、按患者回答代为点选”。
  3. 护士代点时，只读题目原文和 0–10 的说明，不要解释、不要替患者估分。
纸

录入纸质问卷 / 电话询问包括已有 150 例的回录
  1. 患者页面对应时点点 录入纸质/电话。
  2. 选“纸质问卷”或“电话询问”，选“本人填写”或“代填”。
  3. 日期填纸上写的填写日期（不是今天的录入日期）。
  4. 照纸逐题点数字。患者没填的题点“空”，绝对不要点 0。
  5. 19 题都点过后才能保存。保存后这份记录显示“待核对”。
核

双人核对每一份纸质 / 电话录入都要做
  1. 由另一名护士用自己的账号登录（录入人自己不能核对）。
  2. 首页点「待双人核对」，打开记录，点 双人核对录入。
  3. 不看系统里的数，直接照纸质表把 19 题再点一遍，点“提交比对”。
  4. 全部一致：自动标为“已核对”。有不一致：标红的题对照纸质表查——你点错了就改正再比对；第一次录错了就用“修改答案”更正。
改

修改患者的答案录错了、患者当场更正
  1. 患者页面点开那次问卷，点 修改答案。
  2. 输入你自己的登录密码确认身份。
  3. 改需要改的题，每题会显示“原 x → 新 y”。
  4. 选修改原因（必选），点“保存修改”。

原始答案永远保留，谁、什么时候、为什么改都会记录，审查时可以查到。不要用修改去“美化”数据。

催

患者到时间没填：提醒三步每个时点最多联系 3 次
  1. 当天上午 9 点：发消息提醒，点 记录提醒 选“上午 9 点推送”。
  2. 当天晚上还没填：再发一次，记录“晚间补推”。
  3. 第二天还没填：打电话，可以在电话里直接问完 19 题，用“录入纸质/电话”录入。记录“次日电话”。
  4. 三次后仍没完成：点 记为缺失，选原因。不要再追。

每次联系都要点“记录提醒”。论文要报告“自动推送完成率”和“人工干预后完成率”，靠的就是这些记录。

警

出现预警患者提交后自动判定
红色 · 危急任一症状 ≥ 7 分。当天内电话联系。
橙色 · 升高任一症状 4–6 分。下次随访时重点询问。
  1. 打开那次问卷看哪几题分高，电话了解情况。
  2. 按科室预警流程处理：健康指导 / 通知医生 / 建议返院或就医。
  3. 处理完点 记录预警处置，选处理方式、写一句备注。系统自动算出响应用了多长时间。

告诉患者：感觉很不舒服时直接就医或拨打 120，不要等平台回复。平台不做诊断。

周

患者回来做下一个周期化疗新周期 + 上周期结局
  1. 患者页面点「基线资料」，拉到下面点 新增化疗周期，填新的输注开始日。系统自动排好新的 T0/T1/T2。
  2. 在上一个周期里补填结局：期间有没有非计划就诊（日期、门诊/急诊/再入院、主要原因）、计划剂量、实际剂量、下周期推迟了几天。
  3. 点“保存”。
退

患者要退出研究
  1. 患者页面点「基线资料」，拉到最下面「退出研究」，填原因，点确认。
  2. 已交的数据保留，患者账号停用，不会再出现在待随访名单里。
末

研究结束时最后一次随访后
  1. 请患者填 SUS 可用性问卷（纸质），算出 0–100 分。
  2. 在患者「基线资料」页面最下面填“SUS 可用性得分”。

5 条红线

  • 不在系统里写患者真实姓名、身份证号、电话。
  • 没答的题是“空”，不是 0。
  • 不共用账号，不把自己的密码告诉别人。双人核对必须是两个人、两个账号。
  • 不通过微信、QQ 传导出的数据文件。
  • 真实入组开放前（系统显示“真实入组未开启”），只能登记 DEMO 演示患者，用来培训。
